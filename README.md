A program that writes one line, at most 160 characters: the funniest out-of-office auto-reply:

> Out of office: I'm recharging my will to live. Emails will be answered in the order I pretend to have read them.

The line is 112 characters: the holiday is a will-to-live recharge, and the inbox triage is openly admitted fiction.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
